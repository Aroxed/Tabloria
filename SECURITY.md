# Security policy

## Supported version

Security fixes are applied to the latest version of Tabloria Searchable Displays published on WordPress.org.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository:

<https://github.com/Aroxed/Tabloria/security/advisories/new>

Include:

- the affected plugin version;
- the WordPress and PHP versions used for testing;
- clear reproduction steps;
- the expected security impact;
- any suggested mitigation, if available.

Do not include real customer data, credentials, or sensitive CSV files. Please do not open a public issue until a fix is available and coordinated disclosure has been discussed.

We will acknowledge a complete report as soon as practical, investigate it, and provide status updates when there is meaningful progress.
